<product_requirements>
The Glenx MedHub is a full-featured telemedicine mobile app for Ghana, designed to connect patients with various healthcare providers.

**Problem Statement:**
Users in Ghana need a centralized platform to access healthcare services, including online consultations, appointments, prescription orders, and medical diagnostics, with robust support for multiple user roles and secure data management.

**Implemented Features (So Far):**
*   **User Roles & Registration:** Patient, Doctor, Hospital, Pharmacy Shop, Ambulance Hiring Service, Herbalist. Multi-role registration with dynamic role-specific fields for each role's profile.
*   **Patient Features:** Patient registration, doctor search/listing, basic appointment booking, initial AI-powered medical diagnostics (symptom checker), access to a community forum.
*   **Provider Features (Doctor, Hospital, Pharmacy, Ambulance, Herbalist):** Registration, role-specific dashboards displaying relevant information (e.g., appointments for doctors, sales for pharmacies).
*   **AI Medical Diagnostics:** AI chatbot for symptom checking and preliminary suggestions, with backend endpoints for diagnosis and follow-up.
*   **Community Forum:** Backend endpoints for creating, replying to, and searching forum posts. Frontend screens for forum overview, post creation, and detail.
*   **Core App Infrastructure:** Robust FastAPI backend with MongoDB, Expo/React Native frontend with  for navigation, Zustand for state management.
*   **Medical Records, Payments, Notifications, Help & Support:** Backend endpoints and basic frontend screens for managing medical records (view, add, change access code), payments (view, add method), notifications, and help & support (view, create ticket).
*   **Dashboard Enhancements:** Role-specific dashboards for all 6 user types (Patient, Doctor, Hospital, Pharmacy, Ambulance, Herbalist).
*   **Navigation:** Tab-based navigation for main sections, stack navigation for detailed views.
